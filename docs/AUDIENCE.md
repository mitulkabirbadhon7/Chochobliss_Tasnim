# Target Audience & User Personas

## 1. Primary Audience
- Chocolate lovers looking for premium, artisanal products.
- Gift buyers looking for elegant, ready-to-give boxes.
- Health-conscious consumers interested in single-origin, vegan, or low-sugar options.

## 2. User Personas

### Persona A: The Gift Buyer (Amira)
- **Goal:** Find a beautiful, premium gift box and send it directly to a friend.
- **Needs:** Easy navigation, clear shipping options, ability to add a gift note at checkout.
- **UX Implication:** Prominent "Gift Collections" category. Simple, distraction-free checkout flow.

### Persona B: The Chocolate Enthusiast (Rahim)
- **Goal:** Explore unique flavors and buy in bulk.
- **Needs:** Detailed product pages (ingredients, flavor notes, origin), loyalty rewards for repeat purchases.
- **UX Implication:** Rich product detail pages, "Cocoa Points" loyalty system, easy re-order button in the user dashboard.

### Persona C: The Admin (Tasnim)
- **Goal:** Manage inventory, track orders, and update homepage content without touching code.
- **Needs:** Fast, data-dense dashboard, easy product upload forms, scheduled announcement banners.
- **UX Implication:** Clean admin panel with clear data tables and a drag-and-drop CMS for site content.
