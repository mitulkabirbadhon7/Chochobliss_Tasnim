# Chocobliss by Tasnim - Project Overview

## 1. Brand Identity
- **Name:** Chocobliss by Tasnim
- **Vibe:** Premium, Artisanal, Warm, Elegant, Luxury.
- **Color Palette:** Deep Cacao (#1C140D), Cream (#F5EDE4), Terracotta (#C45A3C), Warm Gold (#D4A853).

## 2. Core Concept
An artisanal chocolate e-commerce platform. Guests can browse and view products, but must log in to add to cart and checkout. Features a custom scroll-linked animation on the homepage.

## 3. Tech Stack
- **Frontend:** Next.js 14+ (App Router), TypeScript, Tailwind CSS, Shadcn UI.
- **State Management:** Redux Toolkit (Cart & User Session).
- **Validation:** Zod.
- **Backend:** Next.js Server Actions.
- **Database:** NeonDB (PostgreSQL) with Prisma ORM.
- **Auth:** Supabase Auth.
- **Animation:** HTML Canvas, `requestAnimationFrame`.

## 4. Key User Roles
- **Guest:** Can browse Home, Shop, Product Detail, Announcements, Our Story.
- **Customer:** Can order, view history, manage wishlist, earn Cocoa Points.
- **Admin (Tasnim):** Full access to Admin Panel (Dashboard, Products, Orders, Customers, CMS).
